# Dashboards

The pack ships 8 dashboards. Each folder has the dashboard's help text, a widget list and a screenshot.

- [Rapid vSAN Backpressure](<Rapid vSAN Backpressure/README.md>): Backpressure - which layer is reporting congestion?
- [Rapid vSAN DOM](<Rapid vSAN DOM/README.md>): DOM - how is each layer of a vSAN write performing?
- [Rapid vSAN ESA Write Path](<Rapid vSAN ESA Write Path/README.md>): ESA write path - how are the zDOM layer and segment cleaner performing?
- [Rapid vSAN Host Resources](<Rapid vSAN Host Resources/README.md>): Host resources - what does vSAN itself consume on each host?
- [Rapid vSAN Network](<Rapid vSAN Network/README.md>): vSAN network - how is each layer of the network path behaving?
- [Rapid vSAN Overview](<Rapid vSAN Overview/README.md>): vSAN overview - which layer should you look at first?
- [Rapid vSAN Resync](<Rapid vSAN Resync/README.md>): Resync - how much rebuild work is outstanding?
- [Rapid vSAN Storage](<Rapid vSAN Storage/README.md>): vSAN storage - how is each layer of storage performing?
